# Loki MCP

Queries Grafana Loki logs. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/loki-mcp

Installs from the Camillia hub as `loki-mcp-3c9a34`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
